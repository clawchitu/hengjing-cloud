# ctrl 同步消息接口（MessageType 200 ~ 210）

本文档整理 `MessageType` 200~210 对应的 ctrl 服务接口。接口与 `RealtimeDataReply` 类似：**服务端发送消息给控制屏后同步等待回调，并直接返回结果**，调用方无需再轮询 `ctrl-callback-result`。

## 1. 调用约定

### 1.1 请求

- 方法：`POST`
- 请求体：`ctrlcb.v1.PassCtrlMessageRequest`（JSON，字段名 snake_case）

| 字段         | 类型   | 必填 | 说明                                                                              |
| ------------ | ------ | ---- | --------------------------------------------------------------------------------- |
| `project_id` | string | 是   | 项目 ID                                                                           |
| `user_id`    | string | 是   | 用户 ID                                                                           |
| `body`       | string | 否   | 对应 Query 消息 protobuf 编码后的 **base64** 字符串；Query 为空消息时可传空字符串 |

- 服务端**固定** `message_type`，请求中传入的 `message_type` 会被忽略。

### 1.2 响应

响应体为 `ctrl.v1.GetCallbackResultResponse`：

| 字段   | 类型   | 说明                                                                                  |
| ------ | ------ | ------------------------------------------------------------------------------------- |
| `body` | string | 控制屏回调的 Reply 消息 protobuf 编码后的 base64 字符串，需按下表的 Reply 类型 decode |

### 1.3 错误

| gRPC Code          | 场景                                                    |
| ------------------ | ------------------------------------------------------- |
| `Unauthenticated`  | 用户认证已过期                                          |
| `Unavailable`      | 控制屏消息发送失败（如控制屏未在线，没有可用的 stream） |
| `DeadlineExceeded` | 等待控制屏响应超时（**10 秒**）                         |
| `Internal`         | Redis Pub/Sub 连接关闭等内部错误                        |

## 2. 接口总览

| MessageType | 说明                     | RPC                          | 路由（POST）                              | Query                         | Reply                         |
| ----------- | ------------------------ | ---------------------------- | ----------------------------------------- | ----------------------------- | ----------------------------- |
| 200         | 房间温控数据             | `RoomTemperatureDataGet`     | `/v1/ctrl/room-temperature-data-get`      | `RoomTemperatureDataGetQuery` | `RoomTemperatureDataGetReply` |
| 201         | 房间温控设置             | `RoomTemperatureSet`         | `/v1/ctrl/room-temperature-set`           | `RoomTemperatureSetQuery`     | `RoomTemperatureSetReply`     |
| 202         | 新风除湿机数据           | `FreshDehumidifierGet`       | `/v1/ctrl/fresh-dehumidifier-get`         | `FreshDehumidifierGetQuery`   | `FreshDehumidifierGetReply`   |
| 203         | 统一控制设置             | `UnifiedCtrlSet`             | `/v1/ctrl/unified-ctrl-set`               | `UnifiedCtrlSetQuery`         | `UnifiedCtrlSetReply`         |
| 204         | 运行控制设置             | `RunningCtrlSet`             | `/v1/ctrl/running-ctrl-set`               | `RunningCtrlSetQuery`         | `RunningCtrlSetReply`         |
| 205         | 设备汇总（连接状态）     | `DeviceSummaryGet`           | `/v1/ctrl/device-summary-get`             | `DeviceSummaryGetQuery`       | `DeviceSummaryGetReply`       |
| 206         | 房间开关设置             | `ProjectRoomSwitchSet`       | `/v1/ctrl/project-room-switch-set`        | `ProjectRoomSwitchSetQuery`   | `ProjectRoomSwitchSetReply`   |
| 207         | 空气传感器数据           | `AirSensorGet`               | `/v1/ctrl/air-sensor-get`                 | `TPAirSensorGetQuery`         | `TPAirSensorGetReply`         |
| 208         | 空气传感器数据（按小时） | `AirSensorDataHourGet`       | `/v1/ctrl/air-sensor-data-hour-get`       | `TPAirSensorDataHourGetQuery` | `TPAirSensorDataHourGetReply` |
| 209         | 房间温控数据（按小时）   | `RoomTemperatureDataHourGet` | `/v1/ctrl/room-temperature-data-hour-get` | `TPRoomPanelDataHourGetQuery` | `TPRoomPanelDataHourGetReply` |
| 210         | 运行控制数据             | `RunningCtrlGet`             | `/v1/ctrl/running-ctrl-get`               | `RunningCtrlGetQuery`         | `RunningCtrlGetReply`         |

> 207~209 在 `ctrlcb.proto` 中没有独立的 Query/Reply 消息，前端目前复用 `TP*` 同类消息（见上表）。若控制屏实际使用其他消息，需同步调整 `device.ts`。

调用示例：

```ts
const reply = await setRoomTemperature({
  projectId: '664f1a2b3c4d5e6f7a8b9c0d',
  userId: currentUser.id,
  body: { equipmentId: 1, temperature: 26, switch: 1 },
});
// reply 为已 decode 的 RoomTemperatureSetReply：{ success, msg }
```

## 4. 消息定义

以下均为 `ctrlcb.v1` 包，定义位于 `kxjserver/ctrlcb/api/ctrlcb.proto`。

### 4.1 房间温控数据 `RoomTemperatureDataGet`（200）

**Query**：空消息 `RoomTemperatureDataGetQuery {}`

**Reply**：`RoomTemperatureDataGetReply`

| 字段   | 类型                           | 说明             |
| ------ | ------------------------------ | ---------------- |
| `data` | repeated `RoomTemperatureData` | 房间温控数据列表 |

`RoomTemperatureData`：

| 字段           | 类型                    | 说明                             |
| -------------- | ----------------------- | -------------------------------- |
| `id`           | int64                   | 设备 ID                          |
| `name`         | string                  | 设备名称                         |
| `temperature`  | float                   | 室内温度                         |
| `humidity`     | float                   | 湿度                             |
| `dew_point`    | float                   | 露点                             |
| `set_temp`     | float                   | 设定温度                         |
| `set_humi`     | float                   | 设定湿度                         |
| `wind_speed`   | int32                   | 风速档位，100 为自动风速         |
| `eco`          | int32                   | 节能模式，1 节能，0 标准         |
| `switch`       | int32                   | 开关，1 开启，0 关闭，-1 不变    |
| `mode`         | int32                   | 工作模式，0 制冷，1 制热，2 通风 |
| `end_modes`    | repeated `WorkModeData` | 末端工作模式                     |
| `is_connected` | bool                    | 是否连接                         |

`WorkModeData`：

| 字段          | 类型   | 说明                                                                 |
| ------------- | ------ | -------------------------------------------------------------------- |
| `option_name` | string | 末端名称                                                             |
| `type`        | int32  | 末端类型：风盘 0，顶辐射 1，地暖 2，地冷 3，全空气 4                 |
| `is_selected` | bool   | 是否选中。选中才生效，如只选中地暖，该房间只有地暖工作，其他末端关闭 |
| `is_change`   | bool   | 该末端是否支持关闭（目前仅全空气末端不允许关闭）                     |
| `switch`      | int32  | 开关，1 开启，0 关闭，-1 不变                                        |

### 4.2 房间温控设置 `RoomTemperatureSet`（201）

**Query**：`RoomTemperatureSetQuery`

| 字段           | 类型                    | 说明                                                     |
| -------------- | ----------------------- | -------------------------------------------------------- |
| `equipment_id` | int64                   | 设备 ID                                                  |
| `temperature`  | float                   | 温度                                                     |
| `humidity`     | float                   | 湿度                                                     |
| `wind_speed`   | int32                   | 风速档位，100 为自动风速                                 |
| `eco`          | int32                   | 节能模式，1 节能，0 标准                                 |
| `switch`       | int32                   | 开关，1 开启，0 关闭，-1 不变                            |
| `end_modes`    | repeated `WorkModeData` | 房间末端至少选中一项；如果修改，需要将获取的完整信息传入 |

**Reply**：`RoomTemperatureSetReply { bool success = 1; string msg = 2; }`

### 4.3 新风除湿机数据 `FreshDehumidifierGet`（202）

**Query**：空消息 `FreshDehumidifierGetQuery {}`

**Reply**：`FreshDehumidifierGetReply { repeated FreshDehumidifierData data = 1; }`

`FreshDehumidifierData`：

| 字段                  | 类型   | 说明                 |
| --------------------- | ------ | -------------------- |
| `id`                  | int64  | 设备 ID              |
| `name`                | string | 设备名称             |
| `supply_temp`         | float  | 送风温度             |
| `return_temp`         | float  | 回风温度             |
| `wind_level`          | int32  | 风速档位             |
| `wind_speed`          | int32  | 风机转速             |
| `dehumidifier_status` | int32  | 压缩机状态           |
| `dehumidifier_freq`   | int32  | 压缩机频率           |
| `filter_life`         | int32  | 滤网寿命             |
| `filter_life_p`       | int32  | 滤网寿命百分比       |
| `filter_running`      | int32  | 滤网运行时间         |
| `running_mode`        | string | 运行模式             |
| `running_time`        | int64  | 运行时间             |
| `switch`              | int32  | 开关，1 开启，0 关闭 |
| `is_connected`        | bool   | 是否连接             |

### 4.4 统一控制设置 `UnifiedCtrlSet`（203）

**Query**：`UnifiedCtrlSetQuery`

| 字段            | 类型            | 说明                                |
| --------------- | --------------- | ----------------------------------- |
| `system_switch` | int32           | 系统开关：-1 不变，1 开启，0 关闭   |
| `system_mode`   | `OperatingMode` | 运行模式，见下表                    |
| `room_switch`   | int32           | 房间开关：-1 不变，1 开启，0 关闭   |
| `room_temp`     | float           | 房间温度：-1 不变，其他值为设定温度 |

`OperatingMode`：

| 值  | 含义         |
| --- | ------------ |
| 0   | 不变         |
| 2   | 夏季模式     |
| 3   | 冬季模式     |
| 4   | 通风模式     |
| 5   | 除湿         |
| 6   | 免费制冷模式 |
| 8   | 制热除湿模式 |
| 9   | 供热模式     |
| 10  | 供热加湿模式 |
| 11  | 加湿模式     |
| 12  | 供冷模式     |
| 13  | 供冷加湿模式 |
| 14  | 供冷除湿模式 |
| 15  | 冷热过度模式 |
| 100 | 自动模式     |

**Reply**：`UnifiedCtrlSetReply { bool success = 1; string msg = 2; }`

### 4.5 运行控制设置 `RunningCtrlSet`（204）

**Query**：`RunningCtrlSetQuery`

| 字段           | 类型   | 说明                                 |
| -------------- | ------ | ------------------------------------ |
| `id`           | int64  | 设备 ID                              |
| `name`         | string | 设备名称                             |
| `control_type` | int32  | 当前控制类型：1 露点控制，0 湿度控制 |
| `dew_point`    | float  | 露点                                 |
| `humidity_set` | float  | 设定湿度                             |
| `wind_speed`   | int32  | 设定风速                             |
| `switch`       | int32  | 开关，1 开启，0 关闭，-1 不变        |

**Reply**：`RunningCtrlSetReply { bool success = 1; string msg = 2; }`

### 4.6 设备汇总 `DeviceSummaryGet`（205）

**Query**：空消息 `DeviceSummaryGetQuery {}`

**Reply**：`DeviceSummaryGetReply { repeated DeviceSummaryData data = 1; }`

`DeviceSummaryData`：

| 字段          | 类型   | 说明                             |
| ------------- | ------ | -------------------------------- |
| `device_id`   | int64  | 设备 ID                          |
| `device_name` | string | 设备名称                         |
| `model`       | string | 设备型号                         |
| `address`     | string | 设备地址                         |
| `conn_status` | int32  | 连接状态：0 离线，1 在线，2 异常 |

### 4.7 房间开关设置 `ProjectRoomSwitchSet`（206）

**Query**：`ProjectRoomSwitchSetQuery { int32 switch = 1; }`，开关：1 开启，0 关闭，-1 不变。

**Reply**：`ProjectRoomSwitchSetReply { bool success = 1; string msg = 2; }`

### 4.8 空气传感器数据 `AirSensorGet`（207）

**Query**：空消息 `TPAirSensorGetQuery {}`

**Reply**：`TPAirSensorGetReply { repeated AirSensorData data = 1; }`

`AirSensorData`：

| 字段           | 类型   | 说明           |
| -------------- | ------ | -------------- |
| `name`         | string | 空气传感器名称 |
| `id`           | int64  | 空气传感器 ID  |
| `temperature`  | float  | 温度           |
| `humidity`     | int32  | 湿度           |
| `pm2_5`        | int32  | PM2.5          |
| `co2`          | int32  | 二氧化碳       |
| `dew_point`    | float  | 露点温度       |
| `is_connected` | bool   | 是否连接       |

### 4.9 空气传感器数据（按小时）`AirSensorDataHourGet`（208）

**Query**：`TPAirSensorDataHourGetQuery`

| 字段         | 类型  | 说明     |
| ------------ | ----- | -------- |
| `device_id`  | int64 | 设备 ID  |
| `start_time` | int64 | 开始时间 |
| `end_time`   | int64 | 结束时间 |

**Reply**：`TPAirSensorDataHourGetReply { repeated AirSensorDataHour data = 1; }`

`AirSensorDataHour`：

| 字段                | 类型  | 说明                      |
| ------------------- | ----- | ------------------------- |
| `id`                | int64 | 设备 ID                   |
| `date`              | int64 | 日期（毫秒）              |
| `hour`              | int32 | 小时值                    |
| `temperature`       | float | 空气温度，-100 为无效数据 |
| `floor_temperature` | float | 地面温度，-100 为无效数据 |
| `humidity`          | float | 湿度，-100 为无效数据     |
| `dew_point`         | float | 露点，-100 为无效数据     |
| `co2`               | int32 | 二氧化碳，-100 为无效数据 |
| `pm2_5`             | int32 | PM2.5，-100 为无效数据    |

### 4.10 房间温控数据（按小时）`RoomTemperatureDataHourGet`（209）

**Query**：`TPRoomPanelDataHourGetQuery`，字段同 4.9 的 Query（`device_id` / `start_time` / `end_time`）。

**Reply**：`TPRoomPanelDataHourGetReply { repeated RoomPanelDataHour data = 1; }`，`RoomPanelDataHour` 字段同 4.9 的 `AirSensorDataHour`。

### 4.11 运行控制数据 `RunningCtrlGet`（210）

**Query**：`RunningCtrlGetQuery { int64 device_id = 1; }`

**Reply**：`RunningCtrlGetReply`

| 字段           | 类型   | 说明                                                        |
| -------------- | ------ | ----------------------------------------------------------- |
| `id`           | int64  | 设备 ID                                                     |
| `name`         | string | 设备名称                                                    |
| `control_type` | int32  | 当前控制类型：1 露点控制，0 湿度控制，-1 露点与湿度均不可控 |
| `dew_point`    | float  | 露点，值为 -1 时前端显示 `--`                               |
| `humidity_set` | float  | 设定湿度，值为 -1 时前端显示 `--`                           |
| `wind_speed`   | int32  | 设定风速：0 低，1 高，2 自动                                |
| `switch`       | int32  | 开关，1 开启，0 关闭，-1 不变                               |
| `can_change`   | bool   | 是否可以更改控制类型                                        |
