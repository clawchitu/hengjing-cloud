## /weather、/weather24 入参实测

- `/weather {"city":"苏州"}`、`{"city":"苏州市"}`、`{"city":"320500"}`：均 200，都解析为 320500 苏州。即 `/weather` 也接受 adcode
- `/weather {"latitude","longitude"}` 或 `{"lat","lng"}`：400，`unknown field`，没有经纬度字段
- `/weather {"city":"39.9,116.4"}`：500 `API返回的天气数据不完整`
- `/weather24` 同样没有经纬度字段（400）；`{"city":"116.4,39.9"}` 返回 200 但 `ret_code:-1`，没有数据
- `/weather24 {"city":"320500"}` 200，`areaCode=320500`；`{"city":"北京"}` 200，`areaCode=110000`（直辖市是省级 code）
- 结论：不能直接传经纬度，需要先换成城市名或 adcode
