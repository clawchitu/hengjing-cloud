# 恒境云测试服 /weather 城市覆盖探测

- 时间：2026-11-24；接口：POST /v1/weather {city}，平台账号
- 城市数据：modood/Administrative-divisions-of-China（dist/cities.json + provinces.json），commit c49d495（2025-12-27）
- 方式：脚本逐个城市调 /weather（只读），结果逐条见 `docs/api/weather-coverage-1124.json`（只保留 337 个目标城市）

## 结果

- 测试总数：364（31 省级 + 333 地级；其中 4 个直辖市按省级代码测）
- 地级及直辖市目标：337 个，能查到 337 个，查不到 0 个
  - 按 adcode 直接查到：336，且每个都有 7 天数据（f1~f7）
  - adcode 失败、按名称才查到：1（大理白族自治州(532900)）
- 省级（27 个非直辖市省/自治区）：adcode 全部 500「API返回的天气数据不完整」。按名称"查到"的是模糊匹配到别的城市（河北省→河北区、内蒙古自治区→内江、河南省→河南 等），属于误命中，不算覆盖。
- 返回名称与预期不完全一致：克孜勒苏柯尔克孜自治州 → 返回「克州」（adcode 查询，数据正确）。
- /weather24 抽测 5 个（抚顺、曲靖、唐山、淮北、巴彦淖尔）：adcode 和名称均 200，24 条小时数据。

## 查不到的城市

无（地级及以上全部可查）。仅省级 adcode 不支持。

## 建议

前端本地城市文件用 **6 位 adcode**：336/337 个地级及直辖市直接命中，名称不会有「市/自治州」后缀和模糊匹配的歧义。大理白族自治州（532900）需单独处理：adcode 查不到，用名称「大理白族自治州」可查到（返回「大理」）。
只用地级市粒度，不要用省级 adcode。名称查询对省名会误命中其他城市，不建议作主键。
