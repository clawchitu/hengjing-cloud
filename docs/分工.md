## 3. 约定

1. **文件归属**：共享 hooks 和 `src/api/**` 下的读接口，Claw 可以写。`guard.ts`、写入口、写防护配置只归 Chitu。S9、S10 的下发必须走 S4 的统一写入口。
2. **下发测试**只对 260911001 和 240829001 两个项目做。下发前在群里说一声，下发前后各读一次核对，日志和截图写进 PR。
3. **评审（所有项目通用）**：两路评审，Opus 加 Codex（gpt-6.1-terra），由 PR 作者跑。评论标题用「## Opus 评审」「## Codex 评审」，通过后各发一条「Opus 审核：通过」「Codex 审核：通过」。CI 全绿后由 Chitu 做最后把关（写路径、`src/api`、会话这几处逐行看，其余抽查）再合并。Fable 只用于方案和拆分，不做代码评审。
4. **一个页面只归一个负责人**。要动公共文件，先单独开一个小 PR。截图基线按固定顺序排队，同一时间只允许一个 PR 更新：先 rebase，再用 `-g` 只重录自己那页。
5. **下发测试错开时段**：S9、S10、S12 的下发测试不同时进行。
